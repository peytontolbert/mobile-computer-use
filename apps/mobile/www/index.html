Computer Use

Connect to your trusted local bridge.

Start the bridge on your computer, then enter its LAN URL.

Bridge Setup

Download the desktop app for Windows, macOS, or Linux from GitHub Releases, extract it, then open Mobile Computer Use.

https://github.com/peytontolbert/mobile-computer-use/releases

# macOS/Linux
./mobile-computer-use

# Windows PowerShell
.\mobile-computer-use.exe

The desktop app lets you pick a workspace, start the bridge, approve phones, and remove trusted devices.

Install and sign in to at least one supported provider before starting the bridge.

npm install -g @openai/codex
codex

curl https://cursor.com/install -fsS | bash
cursor-agent login

Enter the printed URL here. It should look like this:

http://192.168.1.25:45731

For remote access, you can use an external IP or hostname if you intentionally port forward the bridge port. Only do this on networks and computers you trust.

Keep the bridge running while you use the app. Source and setup docs are on GitHub: mobile-computer-use.
