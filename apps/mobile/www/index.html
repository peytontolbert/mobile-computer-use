Computer Use

Connect to your trusted local bridge.

Start the bridge on your computer, then enter its LAN URL.

Bridge Setup

Install the bridge on the computer you want to control, then start it on a trusted network.

python -m pip install git+https://github.com/peytontolbert/mobile-computer-use.git
mobile-computer-use-bridge --host 0.0.0.0 --workspace /path/to/allowed/root

Enter the printed URL here. It should look like this:

http://192.168.1.25:45731

Keep the bridge running while you use the app.
